# CareSerenity

**CareSerenity** is a web-based platform designed to connect **orphanages, old-age homes, and charitable organizations** with people who want to support them. Users can **explore organizations, adopt children, donate, volunteer, and participate in seminars/blogs**, while organizations manage everything through a powerful **Admin Panel**.

## Features

### For Users
- Browse all registered organizations (orphanages, old-age homes, etc.)
- View details about organizations, their work, and children list
- Apply for adoption with form submission
- Donate securely to support organizations
- Volunteer registration with approval workflow
- Read blogs, seminars, and organization updates

### For Organizations
- Manage organization profile
- Add/update/remove children records
- Track and manage donations
- Approve/reject volunteer requests
- Create and manage adoption requests
- Launch and manage seminars
- Write and publish blogs for awareness
- Handle user messages & notifications

## Project Structure (Overview)

- assets/ → Images, logos, icons, static files
- chat/ → Chat-related scripts
- css/ → Stylesheets
- database/ → DB-related scripts & configurations
- js/ → JavaScript files
- admin_* → Admin panel pages (dashboard, login, org mgmt, etc.)
- O_* → Organization-side functionalities (profile, orphan, donations, seminars)
- U_* → User-side functionalities (profile, adoption, donations, blogs)
- blog_* → Blog upload, fetch, and view files
- fund_* → Fund management (donations, details, fetch)
- orphan_* → Orphan-related CRUD files
- seminar_* → Seminar management pages
- volunteer_* → Volunteer registration, approval, and management
